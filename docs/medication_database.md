# medication.db 說明

## 檔案位置

`data/medication.db`

## 資料內容

資料來源為臺灣未註銷藥品許可證資料集。

目前包含：

- 官方藥品：22,247 筆
- 官方成分：3,715 筆
- 藥品與成分對應：35,252 筆

## 資料表

### drug

保存藥品許可證字號、中文與英文品名、適應症、劑型、
包裝、申請商、有效日期、用法用量等資料。

### ingredient

保存官方資料中的成分名稱。

### drug_ingredient

保存藥品與成分的多對多關係，並防止相同對應重複建立。

## 相容性注意事項

目前 `server/main.py` 使用的是 `data/drugs.db`，其資料表名稱與
`medication.db` 不同。

`medication.db` 目前作為 B 組員完成的官方資料庫版本與整合參考，
請勿直接將它重新命名為 `drugs.db` 或覆蓋現有檔案。

若要讓後端正式使用，需要調整後端 SQL 或進行資料表格式轉換。

## 使用限制

重複成分比對只表示成分名稱相同，不代表藥物交互作用、
劑量重複或醫療安全判斷。實際用藥應由醫師或藥師確認。
